# 分步界面优化计划

## 目标

新分步模式默认显示，原有长页面保留为经典模式，用户可在顶部随时切换。模式切换只改变界面组织，不改变素材路径、风格、子目录选项、扫描结果或正在进行的任务；仅保存界面模式偏好，不保存本机素材路径。

“不同窗口显示和回退”按同一桌面窗口内的分步页面实现。主流程依次显示素材设置、扫描预览、处理与结果，提供明确的返回入口。优先让常见桌面窗口尺寸下的主要操作保持可见；文件和资源列表分页，长详情在专用对话框中查看，窄短窗口允许必要的局部滚动。

## 页面职责

- 素材设置：选择原片及结果目录，选择标准或鲜艳风格，决定是否包含子文件夹，然后扫描。
- 扫描预览：展示可还原、原样保留和待确认数量，分页核对每个文件的计划与 LUT，可返回修改设置，或开始处理。
- 处理与结果：展示批次进度、取消入口和分页文件状态。结束后打开结果目录、导出报告、回看预览或开始新批次。
- LUT 资源：主流程只保留主动查看入口；自动清单和完整资源库不默认展开。资源查看保留版本、搜索、格式、适用机型和是否可自动使用的说明。

## 状态约束

使用同一套已有业务表单、状态和 API 请求，避免重复绑定或两份批处理逻辑。返回设置而未修改值时保留原预览；任何素材、结果目录、风格或子目录选项变化都会使旧预览失效，必须重新扫描。运行期间保持配置锁定和取消保护；完成后的旧任务只能查看，不能借返回或模式切换重复执行。

保留已有连接状态、重连恢复、导出互斥、新批次及退出逻辑。对话框可通过关闭按钮或 Escape 退出并恢复键盘焦点；原入口因进度更新而被替换时使用可操作的备用入口。分页有明确页码、前后按钮和空状态。

## 验收

独立审查设置失效、返回、模式切换、运行中与完成后的权限、分页边界、空目录和重连恢复。验证常见桌面大小与较小窗口的布局、键盘操作、原生文件夹选择及报告导出。修改后运行相关源码检查，重新生成三个 Electron 平台发行包，检查版本、资源、签名与校验和；Apple Silicon 实际运行验证与 Intel/Windows 交叉构建分别记录。临时素材、截图、日志和本机诊断不进入源码 Git，验收后清理。
