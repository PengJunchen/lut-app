# 使用说明

将对应平台的发行包解压，把 `DJI LUT.app` 或 `DJI-LUT.exe` 放到原片文件夹旁边后启动。应用会在默认浏览器打开仅本机可访问的界面；处理过程都在本机完成。

1. 选择要扫描的原片文件夹。也可以输入文件夹路径。
2. 选择“标准”或“Vivid”。需要扫描子文件夹时勾选递归选项；默认只扫描当前文件夹。
3. 点击“扫描预览”，核对识别结果、匹配的 LUT 和处理原因。
4. 点击“开始处理”。页面会显示文件和进度；取消时，已完成的结果会保留。
5. 完成后打开结果文件夹。关闭应用请使用界面的“关闭应用”按钮；关闭浏览器标签不会退出后台程序。

标准输出位于 `Output/Standard/`，Vivid 输出位于 `Output/Vivid/`。应用读取 DJI 色彩配置元数据来匹配相机、Log profile 和风格。Normal/Rec.709 与 HDR 视频会原样复制；元数据缺失、冲突或没有匹配 LUT 的文件会原样保留并标记待核查。原片不会被覆盖。

应用会将已还原视频重新编码为 10-bit HEVC Rec.709，因此视频像素不是无损转换；音频码流会复制。原样保留的视频会逐字节复制。

macOS 包使用本地 ad-hoc 签名，没有公证；首次打开时按系统提示允许启动。Windows 包没有商业代码签名。
