# 使用说明

将对应平台的发行包解压，把应用放到原片文件夹旁边后启动。Electron 桌面包打开独立桌面窗口，轻量 Go 包在默认浏览器打开本机界面；视频识别和处理都在本机完成。

界面默认采用分步模式，按素材设置、扫描预览、处理与结果切换页面；顶部也可切换到经典模式，现有设置和任务不会重置。各步骤提供明确的前进或返回入口，文件列表分页，完整 LUT 清单只有主动打开后才显示。

1. 在“原片文件夹”一栏粘贴本机目录路径，或点“选择文件夹”打开系统目录选择器。取消选择会保留原路径。
2. “结果保存基础目录”可以留空、手动填写或用“选择文件夹”选目录。留空时结果保存到原片文件夹的 `Output` 目录；“恢复默认位置”会清空此栏。页面会显示本次风格对应的最终 `Standard` 或 `Vivid` 目录。
3. 选择“标准”或“鲜艳”。只有勾选“包含子文件夹”才会递归扫描；默认关闭。
4. 点击“扫描并预览”，确认视频数量、可还原数量、原样保留数量和待核查数量，再核对逐文件识别结果、计划使用的 LUT 与处理原因。待核查项目会原样复制，并且已经包含在原样保留数量中。没有找到视频时，“开始还原”不可用。
5. 点击“开始还原”后，页面显示当前批次的处理状态和进度。处理期间不能更改目录或风格；可以取消处理，已完成的结果会保留。
6. 完成后可打开结果文件夹或导出处理报告。点击“开始新批次”会清除上一批次的预览和进度；新批次必须先重新扫描并预览才能开始还原。

若本机服务连接中断，页面会禁用扫描和还原操作；点“重新连接”恢复服务后可继续。关闭应用请使用界面的“关闭应用”按钮，关闭时会停止正在进行的选择或处理；关闭浏览器标签不会退出后台程序。

应用会读取 DJI 色彩配置元数据来匹配相机、Log profile 和风格。Normal/Rec.709 与 HDR 视频会原样复制；元数据缺失、冲突或没有匹配 LUT 的文件会原样保留并标记待核查。应用不会按文件名或画面猜测模式，不会自动更改风格，也不会覆盖原片。

标准输出位于所选结果基础目录的 `Standard/` 子目录，鲜艳输出位于 `Vivid/` 子目录。若结果基础目录留空，路径分别是 `Output/Standard/` 和 `Output/Vivid/`。应用重新编码的视频使用 10-bit HEVC Rec.709，因此像素不是无损转换；音频码流会复制。原样保留的视频会逐字节复制。

打开 LUT 资源查看入口可搜索版本、机型、模式和用途。标记“仅供查看”的创意、HLG、sRGB、Linear 等 LUT 不会参与自动还原；“自动还原清单”列出当前确实可匹配的版本。版本只在同一机型、输入模式、输出用途和风格之间淘汰旧版，D-Log V2.0 不会淘汰 D-Log2 V1.0。

新增可发现的格式包括 OSV 和裸 H.264/H.265。裸 H.264/H.265 缺乏可靠的内嵌时间戳和机型元数据约定，因此保持原样并标记待核查。OSV 全景、球面投影及多路主视频也保持原样，需先通过适当的工作流导出。识别到扩展名不代表文件一定能解码或匹配 LUT；缺失或冲突的 DJI 元数据仍会保留原样。转换时音频若不能直接封装到 MP4（例如 PCM），结果采用 MKV，以保留音频码流。

macOS 包使用本地 ad-hoc 签名，没有公证；首次打开时按系统提示允许启动。Windows 包没有商业代码签名。
